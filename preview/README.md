# 预览页（开发用，不进安装包）

七个预览页，双击就能在浏览器里打开。都是**先在这里调、定型了再抄进线上代码**的地方。`1.3.0` / `1.3.1` / `1.3.2` / `1.3.3` / `1.3.4` 五页直接加载线上 `../css/style.css` 与 `../js/*`，需要在浏览器里跑真模块（`file://` 下用 Edge/Chrome 打开即可，无扩展环境会退回 localStorage）。

> 无头验证时记得带 `--allow-file-access-from-files`：ES module 在 `file://` 下会被 CORS 拦掉，页面会静默空白，看起来像「脚本没跑」。

## 1.3.4-壁纸题材.html

1.3.4 的验收台：在线壁纸「只要自然风光」。

- 不联网、不碰 Bing：把 2026-10-25 ~ 11-08 这 15 天的真实文案（标题 + 版权说明）写死在页面里，直接 `import { natureGroup, pickNature }` 跑线上分类器，不是手抄一份逻辑。
- 表格逐条列出「判定 vs 期望」，绿=自然、黄=说不清、红=人造，一眼能看出哪条判错。
- 10 条断言：自然 10/10、人造 5/5、边界样本（「石墙边的木制翻越梯，湖区」这类半人造半风景）仍算自然、自然够数时剔除人造、自然不足 4 张时只调顺序不丢图、顺序必须是「自然 → 说不清 → 人造」、空数组与 null 不炸。
- 换词表后要重跑这页；新增样本直接往 `SAMPLES` 里加，格式 `[日期, 标题, 版权文案, 期望档位]`。

## 1.3.3-天气动效.html

1.3.3 的验收台：小雨 / 小雪太弱、晴天光晕在亮底上看不见。

- 加载线上 `js/features/weather.js`，手动 `fxSize → fxBuild → fxPaint` 画**钉住时刻的一帧**，不启动 rAF —— 参数相同，像素就完全相同，改前改后能一张张比。
- 地址参数：`?wx=113|293|323|299|329`（晴 / 小雨 / 小雪 / 中雨 / 中雪）、`?bg=white|light|mid|dark`、`?t=3.2`（动画时刻）、`?shade=0`（关掉晴天暗场做对照）、`?check=1`（显示断言）。
- `paintTo()` 先按 30fps 把前 t 秒走一遍再定格：粒子初值铺在 1.6W × 2.4H 的范围里，只画一帧会显得比实际稀疏一半。
- 16 条断言：小雨根数 / 长度 / 透明度、小雪片数 / 半径 / 近景层、中雨中雪未被串改、雨丝与雪片雪碧图里是否真有冷暗像素、暗场强度是否随壁纸亮度变化，以及**开 / 关暗场两帧在同一区域的平均亮度差**（亮底 2.2%~2.4%，暗底 0.05%）。打开应看到「16/16 通过」。

## 1.3.2-Dock实时调频.html

1.3.2 的验收台：修「点了卡片，智能 Dock 不收录也不调频」。

- 页面直接 import 线上 `js/features/dock.js` 与 `js/core/state.js`，下方 Dock 是真渲染出来的；`window.open` 被拦下用来记录调用时机，`img-src 'none'` 挡掉图标请求，避免 `file://` 下挂住。
- 7 个固定站点、18 条断言：初次收录、次数角标、连点调频、Top5 截断、点击后 `window.open` 同步发生（旧版在 `.finally()` 里会被弹窗拦截）、编辑态不计数、手动模式只记账不重建 DOM、屏蔽站点，以及卡片与 Dock 三处点击链路的源码一致性。打开应看到「18/18 通过」。

## 1.3.1-待办单日翻页.html

1.3.1 的验收台：撕页日历卡左右翻页 + 「看的那天」取数。

## 1.3.0-详情卡片.html

1.3.0 定版的依据：详情模式从「上图下文」改成「左品牌色块 + 右信息板」。

- **直接加载线上资源**：`../css/style.css` + `../js/core/utils.js`，DOM 结构与 `sidebar.js` 的 `makeCard(site, group, detail=true)` 同构，不是照着画一张假图。
- 开关：深/浅主题、紧凑/标准/宽松三档密度、编辑态；也支持地址参数 `?theme=light&density=compact&edit=1`。
- **取色自检区**：用 data-URL 合成四张图标（红色透明标 / 黑色标 / 不透明青色方图 / 全透明图），断言色块颜色、是否描白、空图是否退回首字，结果直接写在页面上。
- 注意：自检用的合成图标是同源 data-URL，画布可读；布局区的真站点走 `/favicon.ico`，跨域读不到像素，会落中性板岩灰 —— 这正是扩展在「没访问过的站」上的表现。

| 预览页 | 线上 |
| --- | --- |
| `.tile` 宽度 `calc(var(--site-rows) - 2px)` | `css/style.css` 的 `body.site-detail .card .tile` |
| 信息板 `.info` | `body.site-detail .card .info`；不另铺玻璃，整卡共用 `.card` 的 `--glass` |
| `img.wht` 描白 | `utils.applyBrandColor()` 里按「不透明像素占比 < 60%」加类 |
| 色块主色 | `utils.extractBrand()`：36 个色相桶、`alpha × 饱和度` 加权，亮度 36–50% / 饱和度 45–72% |
| 首字 → 色块 | `utils.paintLetter()`：容器是 `.tile` 时把底色写到色块上，图标容器保持透明 |

## 1.2.3-壁纸模糊.html

1.2.3 定版的依据：把「背景遮罩」换成「壁纸模糊」。

- 可调：模糊 0–48px、遮罩 0–40%、深/浅主题、三种内置壁纸，还能**上传你自己的壁纸**（照片细节最能看出模糊差别）。
- 三个快捷键：「还原 1.2.2 默认」= 模糊 0 + 遮罩 30%，「推荐值」= 模糊 12 + 遮罩 12%。
- 支持地址参数：`#blur=16&dim=10&theme=light`。
- 将来做**主题模块**时可以直接在这页上加参数（背景模糊、遮罩深浅、壁纸来源都已经是 CSS 变量），不用重画。

| 预览页 | 线上 |
| --- | --- |
| `--bgblur`（模糊半径） | `:root` 的 `--bg-blur`，滑杆写 `document.documentElement.style` |
| `.bg` 的 `inset: calc(var(--bgblur) * -2.4)` | `css/style.css` 的 `.bg`，外扩是为了不露白边 |
| 遮罩层 `--dim` | `.bg-dim` 的 `opacity: var(--bg-dim)`（固定 0.12，不可调） |

## 1.2.2-卡片-C方案.html

1.2.2 定版的依据：只看名字模式——图标左、名字右。

- **参数可调**：壁纸 ×4、主题 ×2、卡片形状 ×2、列宽 180/200/220/248/280、毛玻璃厚度 0–100%、模糊 12/16/22/28/36px、名字折行开关。改完即时生效，右下角能复制参数串。
- **实样是真的**：16 个真实站点走各自根目录的 `favicon.ico`，和扩展运行时同一条路；另有 8 个无图标站点、8 个长名字站点，专门压边界。
- **以后再动卡片**（比如加主题模块、做用户可选卡片样式），先在它上面调，定型了再抄进 `css/style.css` + `js/features/sidebar.js`。

| 预览页 | 线上 |
| --- | --- |
| `.card` 横排、`.ico` 48px、`.name` 两行 `line-clamp` | `css/style.css` 里「1.2.2：只看名字（standard）」那一段 |
| 毛玻璃 60% / 模糊 22px | `:root` 的 `--glass` / `--glass-hover` / `--glass-blur` |
| 首字色块 | `js/core/utils.js` 的 `letterColor()`（强调色 ±120°） |
| 3 秒超时兜底 | `js/features/sidebar.js` 的 `makeCard()` |

# 初见 · Firstlight

![初见 Firstlight](assets/icons/banner.png)

> 本地优先的浏览器新标签页。数据只存在你的浏览器里。

[![License: MIT](https://img.shields.io/badge/License-MIT-5b45e0.svg)](LICENSE)
[![Version](https://img.shields.io/badge/version-1.3.9-1e63e9.svg)](manifest.json)

**初见**把你的新标签页变成一块安静的桌面：分组网站图标、搜索、壁纸、待办、番茄钟、天气、日历，以及一个能聚合多平台文章的 RSS 阅读器。

它不追求功能数量，而是守住三条底线：**没有广告与返利劫持、没有账号体系、不上传任何使用数据**。代码全部开源，可自行审计。

## 功能

| 模块 | 说明 |
| --- | --- |
| 网站分组 | 多分组管理、拖拽排序；卡片可切换「名字 + 简介」与「只看名字」。简介会自动获取，抓不到时用「分组名 · 域名」兜底，不用留白。详情模式是「品牌色块 + 信息板」：色块从图标里取主色，透明底 logo 自动描白，读不到像素时给中性灰而不是瞎猜一个颜色 |
| 收藏夹导入 | 把 Edge / Chrome 收藏夹一键搬进来：一个文件夹变成一个分组，深层子文件夹拍平并入，按网址去重所以重复导入不会出现第二张卡片；导错了能一键撤销。只做一次性拷贝，浏览器里的书签不受影响 |
| 布局密度 | 紧凑 / 标准 / 宽松三档，行列间距递增，可与卡片模式自由组合 |
| 智能 Dock | 底栏自动收录最常访问的 5 个站点并按使用频率排序；点击后当场收录、当场调频，不用刷新页面；也可切手动模式或关闭 |
| 搜索 | Bing / 百度 / Google / DuckDuckGo / 自定义引擎，带搜索建议 |
| 壁纸 | 在线壁纸（每日一张 / 每次新标签 / 定时轮换）、12 款预设渐变、本地图片、纯色，图片壁纸可调模糊（0–40px）。在线壁纸默认**只取自然风光**：Bing 每日图没有题材参数，按返回文案分类，城市 / 建筑 / 遗迹类的图会被筛掉，也可以切回「不限题材」 |
| 待机模式 | 空闲后自动进入极简待机屏：大时钟 + 日期 + RSS 标题跑马灯 |
| RSS 订阅 | 内置轻量阅读器，聚合时间线、按源筛选，支持 RSS 2.0 / Atom / RDF |
| 番茄钟 | 工作 / 短休 / 长休自定义，自动进入下一段，可开关提示音 |
| 待办与日历 | 待办支持悬浮球 / 底栏 / 隐藏三种形态；日历记录日程。面板里的撕页日历卡能左右翻日子，看哪天就翻到哪天，不用开大日历：那天的时间轴、订阅日程、待办一起跟着换，翻回今天点一下「回到今天」 |
| 天气 | 指定城市展示实时天气（城市留空则不取天气，也不做任何定位）；**按当前天气在壁纸上叠加动态效果**（晴光、云影、细雨、飘雪、雾、雷闪），可选择仅待机时播放或常驻播放，也可关闭。亮色壁纸上也给雨丝、雪花和镜头光晕补了暗边与局部暗场，白底不会「什么都看不见」，暗底也不会过曝 |
| 数据同步 | 可选，两种通道任选：**浏览器账号同步**（Edge / Chrome 自带账号同步，增量、零配置）或 **WebDAV**（自己的坚果云等网盘，全量快照、文件本身就是备份）。另有同步状态面板，云端有没有数据一眼可见 |
| 快捷键 | 聚焦搜索、切换编辑模式、打开设置、关闭弹层，全部可自定义 |
| 数据管理 | 一键导出 / 导入 JSON，可恢复默认设置 |

## 安装

### 从源码加载（推荐给开发者）

1. 下载本项目并解压，或 `git clone` 到本地
2. 打开扩展管理页
   - Edge：地址栏输入 `edge://extensions`
   - Chrome：地址栏输入 `chrome://extensions`
3. 打开右上角「开发人员模式」
4. 点击「加载解压缩的扩展」，选择本项目根目录（含 `manifest.json` 的那一层）
5. 新建标签页即可看到初见

### 关于 manifest 里的 `key`（勿删）

`manifest.json` 里的 `key` 是**公钥**，作用是把扩展 ID 固定下来；它不是私钥，公开没有风险。

- 没有 `key` 时，未打包扩展的 ID 由**文件夹绝对路径**派生：Mac 的 `/Users/...` 和 Windows 的 `C:\Users\...` 算出来是两个不同的 ID
- `chrome.storage.sync` 是**按扩展 ID 分区**的，ID 不同 → 两台机器上的「浏览器账号同步」根本不互通
- 有了 `key`，无论在哪个系统、哪个目录加载，ID 都一致（本项目的 ID 是 `oajkgnaikgmpknaafgepnmcnaidijlja`），跨设备同步才成立

所以这个字段不是打包残留，清理代码时请不要删。另外，从商店安装的版本 ID 由发布账号决定，与本地加载版天然不同，两者的数据本来就不互通。

### 关于权限

扩展只申请了必要权限：`storage`（本地保存配置）、`bookmarks`、`history`（用于新建标签页的常用站点建议）、`unlimitedStorage`（保存本地壁纸）。

涉及「阅读站点简介」与「抓取 RSS」时，会**按需**额外申请网站访问权限，你可以随时拒绝，拒绝后对应功能自动降级，其余功能不受影响。

## 隐私

- **数据默认只在本机**：所有配置、分组、待办、订阅源都保存在 `chrome.storage.local` 与浏览器 IndexedDB 中
- **同步是可选项**：开启后走浏览器厂商的账号同步服务（微软 / 谷歌），数据会经过其服务器，关闭则完全本地
- **不收集任何行为数据**：没有埋点、没有统计上报、没有第三方分析脚本
- **不改写你的链接**：站点只按你填写的地址打开，不做任何跳转或返利重写
- **在线壁纸、天气、汇率**等属于运行时向公开接口发起请求，不缓存分发，也不携带任何用户标识

## 本地开发

```bash
# 在项目根目录起一个静态服务
python3 -m http.server 8123

# 浏览器打开
# http://localhost:8123/newtab.html   （主页面）
# http://localhost:8123/rss.html       （RSS 阅读器）
```

预览模式没有扩展 API，会自动降级为 `localStorage`，因此同步、权限申请、站点简介抓取等功能在预览下不可用，属预期行为。

## 打包

```bash
cd <项目根目录>
git archive --format=zip --prefix='' -o ../初见-<版本>.zip HEAD
```

用 `git archive` 而不是 `zip -qr .`：后者会把 `.git` 整个仓库历史打进包，体积大几倍。详见 `RELEASING.md`。

产物是一个可直接上传到扩展商店、或分发给他人解压加载的压缩包。

## 目录结构

```
.
├── manifest.json          # 扩展清单（MV3）
├── newtab.html            # 新标签页入口
├── rss.html               # RSS 阅读器
├── css/                   # 样式（主样式 + RSS 页样式）
├── js/
│   ├── app.js             # 入口：加载数据、编排模块、时钟与待机调度
│   ├── core/              # store 持久化 / state 全局状态 / sync 同步 / utils
│   └── features/          # 各功能模块（搜索、壁纸、待办、Dock、天气、番茄钟…）
├── assets/icons/          # 品牌图标与横幅（SVG 源文件 + 各尺寸 PNG）
├── DESIGN.md              # 设计说明：架构分层、存储与同步、天气动效、扩展指引
├── CHANGELOG.md           # 逐版变更
└── RELEASING.md           # 发版流程
```

存储按段拆分（`settings` / `todos` / `dock` / `events` / `stats` 等），每段带独立时间戳，既是同步合并的依据，也避免了单块数据损坏影响全局。分组再细分一层：`monk.groupidx.v1` 存分组顺序，每个分组单独一条 `monk.group.<id>.v1`，这样一个分组变大不会拖累其它分组，浏览器同步的 8KB 单项上限也从「全部站点」变成「每组约 49 个站点」。

想改代码或接手维护，先读 [DESIGN.md](DESIGN.md)：里面有架构分层、存储与同步模型、天气动效子系统、踩过的坑，以及「哪些事是刻意不做的」。

## 第三方服务声明

本扩展的在线壁纸、天气、汇率、搜索建议等数据来自第三方公开服务（Bing、Lorem Picsum、wttr.in、Frankfurter 等），相关内容版权归原权利人所有。扩展仅在运行时请求并展示这些数据，不打包、不再分发任何第三方素材。各网站名称与图标归其各自所有者所有，本项目仅作指示性引用。
